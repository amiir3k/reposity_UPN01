# Mesa de partes digital – Centro de Salud (prototipo)

Prototipo en Python 3 del desafío «Del archivador al algoritmo» (Fundamentos de Programación – CIIN1205P, Grupo 05).

- `principal.py`: menú del sistema.
- `funciones.py`: registrar, eliminar, buscar (DNI, código, área), listar y ordenar por código.
- `expedientes.json`: expedientes guardados (datos ficticios de prueba).

Ejecutar: `python3 principal.py`

Solo guarda datos administrativos del trámite; no guarda información clínica.
